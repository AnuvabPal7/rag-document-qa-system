## Tell me about the SecureSign project.
SecureSign is a full-stack digital document signature application I built. It allows users to securely upload PDFs, place signatures via drag-and-drop, and share documents for signing. I implemented JWT authentication with Spring Boot and MySQL for user and document management, integrated Apache PDFBox for digital signature stamping, and used the Resend API for email-based signing workflows. The React frontend handles signature placement, and the application is deployed using Docker, with the backend on Render, frontend on Vercel, and database on Railway MySQL.

## Tell me about the RAG-Based Document Question Answering System.
This is a Retrieval-Augmented Generation pipeline I built for semantic question answering over custom documents. It uses HuggingFace embeddings with a ChromaDB vector store for efficient semantic retrieval, with document chunking and metadata-based category filtering to improve relevance. I integrated Groq's Llama 3 model via LangChain for answer generation, and built a Streamlit interface that shows source traceability for every answer.
